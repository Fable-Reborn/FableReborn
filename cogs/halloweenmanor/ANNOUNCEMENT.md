# Hollow Manor — announcement draft

The window on the hill is lit again.

**The Hollow Manor** opens in its own channel when the GMs call it. You do not type. You choose.

- **Investigate** if you want to search the house. Each room gives you a private choice, and searching is what fills the picture's bar. Active searchers earn more bones, better bag odds, and a chance at the new profile theme.
- **Keep watch** if you want to stand at the gate. You still earn bones. Not nearly as many.

Bones still spend in `$spookyshop`. The seasonal background this year is **The Last Lantern**, a profile theme for 2,500 bones. After you own it, `$prpg themes` and `$prpg theme hallowmanor`.

The paintings on the manor message change as you go deeper. The bar on that picture is the house, filling.

# The woods have no walls — chaos night

The house was never the only door.

All week the woods kept *one* threshold: a single latch, a single knock, a single visitor. That was courtesy. The forest can be polite when it wants something from you.

Tonight it does not want anything. Tonight it remembers it does not have walls.

**The paths are opening.** Not at the top of the hill. Not in a neat line. A door above the first channel, a door above the next, a door above the next — fourteen ranks through the Halloween halls, each one a real knock, each one choosing its own visitor. If you have been waiting on the leaves, this is the night the leaves run out.

Night Watch will be called **once**. After that, hunt. You can knock more than one door. Crumbs still pay. Tricks still mock. Treats still feed. And if a door goes pale, the blessing is running as hot as it ever will: the last odd window, nothing lower.

The manor still stands. The shop still takes bones. The house can still give you a skin it has been keeping in other rooms — Hollow Rider, Wraithwake, Bonecourt Revel, The Last Lantern. Equip them in `$prpg themes`.

When the last latch turns, the woods go still. Until then: **Knock.**

`$night watch` if you want the ping. The doors will show for everyone.
