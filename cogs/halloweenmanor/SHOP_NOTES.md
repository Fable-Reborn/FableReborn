# Halloween cog — Changelog

## [2026-09-29]

### Added

- **`$spookyshop` item 7, The Last Lantern.** This replaces the seasonal background. 2,500 bones, one purchase, using the existing `ssbg` stock. It grants the `hallowmanor` profile theme for `$prpg themes`. Equip it with `$prpg theme hallowmanor`. A second purchase is refused instead of charging again. The old event-background image is not sold.

### Fixed

- Rare crate now costs 60 bones, matching the shop listing.
- Magic crate purchase text now says 250 bones, matching the amount charged.
- `$ss buy` with an item number outside 1–10 now replies that the choice is invalid.

The Hollow Manor raid lives in `cogs/halloweenmanor/` and has its own changelog.
